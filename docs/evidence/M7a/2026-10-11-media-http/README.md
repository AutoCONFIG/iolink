# M7a media HTTP/HLS gateway seam

This scoped increment adds provider-neutral manifest and segment ports, playback authorization and HLS rewriting, and the disabled-by-default HTTP handler for `/media/v1/{token}/{session_id}`. It does not enable a provider or claim a real ZLMediaKit integration.

## Implemented boundaries

- Every manifest and segment request verifies the dedicated playback token and current session through `playback.Service.AuthorizeMedia`.
- Pending sessions return HTTP 425 with `Retry-After: 1`; invalid token, forbidden, unknown mapping, unavailable provider and rejected media map to 401, 403, 404, 503 and 502 respectively.
- Manifest responses are limited to 256 KiB and segment responses to 8 MiB. Manifest and segment fetches have 3 second and 10 second default deadlines.
- Only the restricted date/hour TS path layout is accepted. Master playlists, URI-bearing tags, keys, maps, byte ranges, external paths, traversal, encoded paths and query/fragment data are rejected.
- Segment IDs are generated by the application and persisted through one batch mapping operation; client supplied IDs are never used as provider paths. The mapping adapter must commit the batch atomically and return no rows on failure.
- Media responses set `Cache-Control: no-store` and `Referrer-Policy: no-referrer`.
- `MaxManifestBytes` (256 KiB) and `MaxSegmentBytes` (8 MiB) are part of the media contract. A provider adapter must enforce these limits while reading upstream data before returning a byte slice; the gateway check is a second boundary. No external provider is enabled in this increment.

## Verification

Environment: Go toolchain in the repository workspace, no external media provider.

Command:

```text
go test -race -shuffle=on -count=1 ./internal/mediahttp ./internal/playback
go vet ./internal/mediahttp ./internal/playback
git diff --check
```

Observed:

```text
ok  git.hyhy.fun/rsplab/iolink/internal/mediahttp  1.036s
ok  git.hyhy.fun/rsplab/iolink/internal/playback   1.012s
```

The tests cover successful same-origin rewrites and TS delivery, no-store headers, pending/425, invalid paths, unsafe and unknown HLS tags, atomic mapping failure with no residual rows, unknown mappings, and the 8 MiB segment limit. Real ZLMediaKit, RTSP cameras, browser playback, and external network acceptance remain `external_blocked` for this seam.
